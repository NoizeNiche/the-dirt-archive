# Ampeg Dirt Catalog Audit 01

## Scope
Manufacturer/product census for Ampeg-branded effects with direct relevance to overdrive, distortion, or fuzz. This audit intentionally separates original 1960s production, later reissues, and modern name-revival products.

## Verified core dirt lineage

| Model / identity | Period | Archive status | Notes |
|---|---:|---|---|
| Ampeg Scrambler / SC-1 | 1969–c.1970 | VERIFIED | Original Ampeg octave-fuzz / distortion pedal. Contemporary and later historical sources consistently place first release in 1969 and describe a short production run. |
| Ampeg Scrambler SCP-OD reissue | 2005–2006 | VERIFIED | USA-made reissue of the original Scrambler design/cosmetic concept. Keep separate from 1969 specimens. |
| Ampeg Scrambler Bass Overdrive | 2017–present-era product family | VERIFIED / DISTINCT MODERN PRODUCT | Modern product using the Scrambler name but marketed as a bass overdrive. Do not merge automatically with the 1969 octave-fuzz lineage. |
| Ampeg SCR-DI | modern | VERIFIED / COMPOSITE PRODUCT | Bass DI/preamp containing a Scrambler Bass Overdrive section. Treat as a system/product integration rather than another standalone Scrambler generation. |

## 1969 Scrambler: historical anchors

Ampeg's original Scrambler appeared in 1969. Later historical accounts commonly put total production in roughly the 2,000–2,500 unit range, while other secondary sources give slightly different estimates. The archive should therefore preserve the range rather than promoting a single exact production count until stronger primary documentation is located.

The original pedal is consistently described as an octave-fuzz / distortion effect with a distinctive upper-harmonic behavior and a clean/effected blend relationship. It is a core Ampeg dirt product and belongs in the main dirt catalog, not merely a bass-effects footnote.

Original-period documentation and later historical sources also indicate that the original design was available with a very unusual control concept centered on **Texture** and **Balance**. The exact circuit implementation is outside the archive's public scope and is not reproduced here.

## 2005 SCP-OD reissue

Ampeg reissued the Scrambler in summer 2005 under the SCP-OD designation. Analogman's historical comparison describes the reissue as unusually faithful while noting audible/output differences from originals. Reverb specimen listings identify USA-made 2005 examples, with some listings grouping production around 2005–2006.

Archive rule: **1969 original != 2005 SCP-OD reissue**. The reissue should have its own generation/production-period node and should not be used as evidence for the construction of an original 1969 specimen.

## Modern Scrambler naming corridor

The modern Ampeg Scrambler Bass Overdrive is a separate product generation and product objective. Current Ampeg materials describe it as an all-analog bass overdrive with Drive and Blend controls and a focus on Ampeg-style grit, grind, and sag. The current product documentation does not establish identity with the 1969 octave-fuzz circuit.

Because the same retail name spans materially different eras, the archive should use:

**Ampeg entity → Scrambler family/name → 1969 Original / 2005 SCP-OD / modern Bass Overdrive generations**

rather than a single flat "Scrambler" entry.

## Dirt-adjacent boundary: Sub-Blaster

The 2005-era Ampeg pedal lineup also included the **Sub-Blaster**, an octave-down effect designed for sub-bass augmentation. Ampeg's own manual presents it as a frequency/octave effect used alongside a signal chain that can include distortion/fuzz. It is therefore **not counted as a core Ampeg dirt pedal** in this audit. It may receive a separate effects-family record later.
