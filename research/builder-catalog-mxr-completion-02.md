# MXR Dirt Catalog Completion 02

Research date: 2026-09-14

Status: breadth-first catalog reconciliation. Original MXR production is kept separate from Jim Dunlop-era continuation/reissues.

## Canonical identity

Canonical builder/brand: MXR. Historical builder identity begins with the original Rochester, New York operation; Jim Dunlop later acquired and resurrected the brand. The archive should retain ownership and production transitions instead of creating duplicate builder entities.

## Foundational original dirt products

- Distortion+
- Blue Box Octave Fuzz

Dunlop's current MAP/product material still identifies M103 Blue Box and M104 Distortion+ as active MXR model numbers, supporting the continuity of these core catalog identities while historical production eras remain separate. [https://www.jimdunlop.com/map/]

- Super Badass Distortion (M75)
- Custom Badass Modified O.D. (M77)

- Bass DI+ (M80, dirt-adjacent bass product)
- Bass Fuzz Deluxe (M84)

Current Dunlop product listings substantiate the M75, M77, M78, M84, M85, M116, M236 and M249 dirt families and the broader MXR catalog numbering scheme. [https://www.jimdunlop.com/products/electronics/mxr/]

## Historical treatment rules

Distortion+ requires cross-era generation work because original MXR production and Dunlop-era continuation are not automatically identical physical production states.

Blue Box should be treated as an octave-fuzz family with edition/reissue states rather than a generic fuzz tag.

Bass DI+, Bass Fuzz Deluxe and Bass Distortion belong in the dirt story but should retain bass-product classification so the archive can answer both guitar and bass historical questions.

Artist/signature models, limited runs, and Dunlop-era redesigns should be attached to the canonical MXR entity without erasing the original MXR production lineage.
