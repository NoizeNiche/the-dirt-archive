# Builder -> Pedals Research Block 179

## Scope

Continued the C-section Builder -> Pedals census with dirt-only inclusion: overdrive, distortion, fuzz. Existing canonical builders were checked against the master index before creating new identities. Utility, modulation, delay, routing, boost-only, and other non-dirt products were excluded.

## Existing canonical builder expanded

### ID 366 — Citadel Electronics
- Vector — Fuzz

Citadel's current product catalog includes Vector as a hybrid octave fuzz pedal. This is an expansion of the existing Citadel identity, not a new builder.
