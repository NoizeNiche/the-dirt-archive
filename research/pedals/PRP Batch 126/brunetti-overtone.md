# Brunetti — Overtone

## PRP identity

- **Builder:** Brunetti
- **Catalog type:** Overdrive
- **Identity:** Brunetti all-tube pedal preamp/overdrive.

## What this pedal is

Overtone is an early Brunetti pedal product documented from 2006. Effects Database classifies it as boost/preamp and overdrive, while Brunetti's related documentation describes the Overtone architecture as an all-tube unit capable of being used as a preamp. [1][2]

## Colorways

No reliable production finish established.

## Versions and factory options

- Boost/preamp/overdrive format
- All-tube architecture documented for the Overtone line
- Foot-pedal format
- No numbered factory revision verified for this base identity [1][2]

## Version changes

Overtone 2 is retained as a separate catalog identity because it is documented as the expanded 2+1-channel form of the Overtone. [2]

## Transistor

- **Technology:** Tube.
- Transistor devices are not applicable to the documented gain architecture.

## Diode

Exact clipping diode devices are not publicly documented.

## Sound

Overtone was designed to add substantial amp-style color rather than function only as a simple clean boost. The documented Overtone line spans warm/fat tones through more aggressive drive and is intended to interact with an amplifier/preamp setup. [2]
