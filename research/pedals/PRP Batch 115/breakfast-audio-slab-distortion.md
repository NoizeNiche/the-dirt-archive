# Breakfast Audio — SLAB DISTORTION

## PRP identity
- **Builder:** Breakfast Audio
- **Catalog type:** Distortion
- **Identity:** Analog high-gain/octave-up distortion pedal.

## What this pedal is
SLAB DISTORTION is a high-gain analog distortion with an octave-up mode. Surviving technical documentation describes a three-stage op-amp distortion path, with the third stage based on the Traynor TS-50 / Rusty Box concept and a second mode that uses a transformer to create octave-up waveform chopping. ## Sound
SLAB is built for large, saturated distortion rather than low-gain breakup. Its octave mode adds a raw upper-octave layer by chopping the waveform, giving the pedal a more aggressive and synthetic edge than the base distortion voice. [1]
