# Build Your Own Clone — Mighty Mouse

## PRP identity

- **Builder:** Build Your Own Clone
- **Catalog type:** Distortion
- **Identity:** RAT-family distortion/overdrive kit with multiple clipping configurations.

## What this pedal is

Mighty Mouse is a BYOC RAT-based design intended to expand the circuit's range beyond the stock RAT sound.

## Modes and versions

The documented 2006 version provides vintage, big-boost, and overdrive modes. The later 2009 description documents a six-position clipping selector:
1. Vintage symmetrical distortion
2. Turbo distortion
3. Asymmetrical distortion
4. Symmetrical overdrive
5. Asymmetrical overdrive
6. MOSFET overdrive

## Active device

- LM308 op amp is documented for the Mouse design.

## Sound

The documented modes span RAT-style distortion through multiple overdrive and boost configurations. The archive does not merge those modes into a single generic tonal description.
