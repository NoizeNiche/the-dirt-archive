# Build Your Own Clone — Li'l Mouse

## PRP identity
- **Builder:** Build Your Own Clone
- **Catalog type:** Distortion
- **Identity:** Compact ProCo RAT-family kit.

## What this pedal is
Li'l Mouse is the small-format BYOC RAT design. The surviving source material identifies it as a compact RAT-based build using an N.O.S. LM308 op amp.

## Construction
- Small-format enclosure.
- All through-hole components.
- Panel-mounted hardware.
- True bypass.

## Version changes
The Li'l Mouse is the compact version of the BYOC Mouse family. Unlike the full-size Mouse, the documented Li'l version keeps the classic three-control format rather than the larger Mouse's expanded clipping options.

## Active device
- N.O.S. LM308 op amp is documented.

## Sound
The RAT circuit family is the confirmed reference point. The archive does not assign additional component or voicing claims beyond the documented design.
