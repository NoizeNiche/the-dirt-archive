# Cat Box Customs Bean Machine

- **Builder:** Cat Box Customs
- **Catalog type:** Fuzz
- **Catalog identity:** Bean Machine
- **What this pedal is:** A hand-painted Harmonic Percolator-inspired fuzz with selectable clipping and additional octave/intensity options.
- **Colorways:** Each enclosure was hand-finished, so many individual paint patterns and colorways exist rather than one fixed finish.
- **Versions:** Bean Machine V1 / original production model.
- **Version changes:** V1 uses a three-way clipping choice plus two additional toggles; V2 expands the same concept into a deluxe version with more controls and a feedback section.
- **Transistor type:** Not documented in the reviewed source.
- **Diode type:** D310 germanium, no-clipping, and Schottky BAT41 options are documented.
- **Controls / switching:** Volume and Fuzz controls, three-way diode selector, pseudo-octave up/down option, and intensity option.
- **Power:** Boss-style 9V power supply only; no internal 9V battery clip.
- **Sound:** Bean Machine can move from lighter, articulate percolator-style breakup into raw, gated fuzz, while the octave and clipping choices radically alter the texture. Its hand-built design intentionally leaves room for aggressive, nonlinear sounds.
- **Research confidence:** High.
