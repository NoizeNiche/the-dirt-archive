# Barge Concepts — BP-1

## PRP identity
- **Archive parent:** BP-1
- **Builder:** Barge Concepts
- **Catalog type:** Distortion / Fuzz / Overdrive
- **Identity:** Enhanced Interfax HP-1 Harmonic Percolator implementation with switchable input/output buffering, true bypass and optional output-buffer gain. [1][2]

## What this pedal is
Barge Concepts describes the BP-1 as an enhanced implementation of the vintage Interfax HP-1 Harmonic Percolator, reverse-engineered from photographs and later-discovered circuit details. With both buffers disabled, the builder states that it closely reproduces the original HP-1 operating behavior. [1]

## Controls / architecture
- **DRIVE**
- **BALANCE**
- **HARMONICS**
- Switchable input buffer.
- Switchable output buffer.
- Overall 3PDT true-bypass footswitch.
- Dual-color status LEDs indicating switching states. [1][2]

## Circuit lineage
- **Primary lineage:** Interfax **HP-1 Harmonic Percolator**.
- Input buffer can provide up to **20 dB** of gain.
- Output buffer is low impedance and can be configured with additional fixed gain in later/custom implementations.
- The buffer stages can be disabled to preserve the original-style passive interaction. [1]

## Version / factory options
### Stock BP-1
Input and output buffering can be bypassed so the core response remains close to the HP-1 behavior.

### Modified/V2-era output gain
Barge Concepts documents configurations with fixed output-buffer gains of approximately **+5, +10 or +15 dB**, and a custom fourth control can provide variable output gain up to +15 dB. [2]

## Construction / hardware
- High-impedance input buffer.
- Low-impedance output buffer.
- 3PDT true bypass.
- Dual-color status LEDs.
- Compact stompbox enclosure.
The exact documented build is a custom/prototype-oriented Barge Concepts design. [1][2]

## Sound
The BP-1 is intended to preserve the harmonic-forward, touch-sensitive behavior associated with the HP-1 when the buffers are disabled. Engaging the buffers changes loading and practical gain behavior without requiring the core circuit to become a conventional hard-clipping distortion. [1]

## Deep research verification
Effects Database and the exact-model Barge Concepts references were cross-checked. The independent database explicitly identifies the BP-1 as an enhanced Interfax HP-1 implementation and documents the high-impedance input buffer, low-impedance output buffer and true-bypass architecture. [1][2]
