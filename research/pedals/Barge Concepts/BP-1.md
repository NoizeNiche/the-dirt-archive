# Barge Concepts - BP-1

## PRP identity
- **Archive parent:** BP-1
- **Builder:** Barge Concepts
- **Catalog type:** Distortion / Fuzz / Overdrive
- **Identity:** Enhanced Interfax HP-1 Harmonic Percolator implementation with switchable input/output buffering and optional output-gain modifications.

## What this pedal is
BP-1 is based on reverse-engineering the Interfax HP-1 Harmonic Percolator. Barge Concepts adds a high-impedance input buffer, low-impedance output buffer, true bypass, and internal switches that let the user preserve the original-style passive interaction or add buffered drive.

## Colorways
- A documented production example uses a dark gray/black enclosure with silver edging.
- No complete factory colorway chronology was verified.

## Versions and factory options
### BP-1
- Drive
- Balance
- Harmonics
- Switchable input buffer
- Switchable output buffer
- 3PDT true bypass
- Dual-color status LEDs

### V2 / custom output-gain option
- Output buffer can be configured for +5, +10, or +15 dB fixed gain.
- A fourth front-panel pot can be added for variable output gain up to +15 dB.

## Version changes
The documented V2-era modification adds optional output-buffer gain. The stock configuration with the buffers disabled is intended to closely reproduce the HP-1 operating behavior, while buffered configurations add practical drive and loading flexibility.

## Sound
With the buffers disabled, BP-1 preserves the touch-sensitive, harmonic-forward character associated with the HP-1. Engaging the input buffer and raising Drive expands it from mild boost into heavy grit, while output buffering helps with long cables and difficult loads without intentionally adding hard-clipping coloration.
