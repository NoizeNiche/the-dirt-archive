# Arcane Analog - NKT775 WHITE FUZZ FACE

## What this pedal is
A modern Fuzz Face build using NOS NKT775 white-dot germanium transistors. The documented Daphne Blue build adds external Bias to the standard Gain/Fuzz layout.

## Colorways
- Daphne Blue enclosure with custom etched top plate is documented.

## Versions and factory options
- Gain, Bias, Fuzz
- NOS NKT775 white-dot germanium transistors
- DC power, LED, true bypass, veroboard
- Custom powder-coated enclosure and etched plate

## Version changes
This is a transistor-specific Fuzz Face configuration rather than a numbered production revision. External Bias expands the standard control set.

## Transistor
- NOS NKT775 white-dot germanium transistors.

## Diode
- Exact clipping diode/device is not publicly documented.

## Sound
The germanium Fuzz Face format is aimed at warm, responsive fuzz with strong cleanup and bias sensitivity. External Bias expands saturation and texture beyond a fixed-bias two-knob format.
