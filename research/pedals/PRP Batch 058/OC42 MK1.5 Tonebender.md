# Arcane Analog - OC42 MK1.5 Tonebender

## What this pedal is
A specific MK1.5 Tone Bender run using three NOS Mullard-branded OC42 germanium transistors and a phenolic board. Arcane Analog describes the run as having more bite and better mix-cutting ability.

## Colorways
- Silver and green enclosure examples are documented.

## Versions and factory options
- Level, Fuzz
- NOS Mullard OC42 germanium transistor trio
- Suflex and Philips capacitors
- Carbon-composition resistors
- Phenolic board
- Hand-wired construction
- Limited run of three units

## Version changes
This is a specific OC42-equipped run, distinct from the broader Tone Benders family listing.

## Transistor
- 3 x NOS Mullard-branded OC42 germanium transistors.

## Diode
- Exact clipping diode/device is not publicly documented.

## Sound
The MK1.5 platform is dense and woolly with more bite than a Fuzz Face, and Arcane Analog tuned this run for stronger cut in a band mix. The design emphasis is aggressive fuzz texture with articulation.
