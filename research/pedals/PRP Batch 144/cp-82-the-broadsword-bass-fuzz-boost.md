# Caline CP-82 The Broadsword Bass Fuzz + Boost

- **Builder:** Caline
- **Catalog type:** Fuzz
- **Catalog identity:** CP-82 The Broadsword Bass Fuzz + Boost
- **Colorways:** Red enclosure with black sword artwork is documented in exact-model listings.
- **Versions:** The design combines fuzz with a separate boost footswitch.
- **Version changes:** No confirmed production hardware revision was found. One demo source used the alternate nickname “Foe Hammer,” but the archive keeps the tracker’s canonical name “The Broadsword.”
- **Transistor type:** Caline/Effects Database documentation explicitly describes a vintage germanium transistor design; the exact transistor type or part number is not given.
- **Diode type:** Not documented in the reviewed sources.
- **Controls / switching:** Fuzz and Volume controls, separate Boost and On/Off footswitches, true bypass.
- **Sound:** The CP-82 is a bass-oriented vintage fuzz designed to move from cleaner material into thick, smoother fuzz while retaining a dedicated boost function. The published description specifically calls out germanium-transistor construction and vintage fuzz character rather than a modern high-gain distortion approach.
- **Research confidence:** High for the fuzz/boost layout and the published germanium-transistor statement; medium for deeper circuit lineage because no schematic was located.
