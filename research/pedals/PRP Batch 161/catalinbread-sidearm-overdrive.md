# Catalinbread SideArm Overdrive

- **Builder:** Catalinbread Effects
- **Catalog type:** Distortion / Overdrive
- **Catalog identity:** SideArm Overdrive
- **What this pedal is:** A reworked 1979-style green overdrive with expanded gain range, a 720 Hz Mids control, and a tilt-style Tone control.
- **Colorways:** Current SideArm is part of Catalinbread's '70s Collection; cosmetic differences are not treated as separate identities.
- **Versions:** SideArm Overdrive; later revision language exists on the current product page, but no separate catalog identity is asserted here.
- **Version changes:** The current Catalinbread page notes a later revision with a gentle treble filter above 16 kHz; exact production transition details are not established.
- **Transistor type:** Not documented.
- **Diode type:** Not documented.
- **Controls / switching:** Drive, Tone, Mids, Volume.
- **Power:** 9–18V DC, center-negative.
- **Factory modifications:** None documented.
- **Sound:** Ranges from clean boost through substantially more gain than a typical Tube Screamer, with adjustable 720 Hz mids and a 1 kHz tilt EQ.
- **Research confidence:** High.
- **Sources checked:** https://catalinbread.com/products/sidearm-overdrive-1 ; https://pedalfilter.com/catalinbread/sidearm-overdrive
