# Bad Penny FX - The Fuzz Controller V1

## PRP identity
- **Archive parent:** The Fuzz Controller V1
- **Builder:** Bad Penny FX
- **Catalog type:** Fuzz / Overdrive
- **Identity:** 2019 version of Bad Penny FX's original Fuzz Controller, using a high-gain silicon fuzz transistor and switchable clipping/voicing controls.

## What this pedal is
A Bad Penny FX 2019 listing describes the Fuzz Controller as the builder's debut original effect pedal, combining vintage component choices with a modern high-gain silicon transistor. The design provides multiple switchable voicings around the fuzz stage.

## Colorways
- A documented example uses a hand-shaped aluminum top with a mitred English Ash enclosure.
- No complete factory colorway chronology was verified.

## Versions and factory options
### V1 / 2019
- Gain, 1 kB bias control
- Master Volume, 500 k
- 47 k starve switch
- Diode selector: 1N4148 or red LED
- Bass-cut switch
- Treble-cut switch
- True bypass
- Standard Boss-type 9 V center-negative supply
- Neutrik jacks
- Vintage Philips, K40Y-9, Sprague Vitamin Q and Tropical Fish capacitors
- Vintage carbon resistors
- 22 AWG cloth wiring

## Version changes
The 2019 listing identifies this as the Fuzz Controller's original/debut version. It also distinguishes this build from a retrofit by its vintage 3.3 Philips input capacitor. A later Fuzz Controller V2 was fully redesigned, so V1 and V2 are maintained as separate archive records.

## Transistor
- **Technology:** High-gain silicon fuzz.
- **Exact device:** The listing documents a modern high-gain silicon transistor but does not give a part number.

## Diode
- **Clipping selector:** 1N4148 or red LED.
- The source describes the 1N4148 setting as harder clipping and the red LED setting as closer to overdrive-level gain behavior.

## Sound
The V1 Fuzz Controller spans from gentler dirt to very high-gain fuzz, with the starve control imitating the reduced-voltage behavior of a dying battery. The diode selector, bass cut, treble cut, and bias/gain controls let it move between harsher, compressed fuzz and more open overdrive-adjacent textures.
