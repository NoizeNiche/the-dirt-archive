# Bad Penny FX — The Fuzz Controller V2

## PRP identity

- **Archive parent:** The Fuzz Controller V2
- **Builder:** Bad Penny FX
- **Catalog type:** Fuzz
- **Identity:** Fully redesigned high-gain silicon Fuzz Controller that adds power filtering, boost stages, starve control and internal output trims to the original platform. [1]

## What this pedal is

Bad Penny FX explicitly describes V2 as a **full redesign**, retaining the high-gain silicon fuzz concept while adding more controllable gain architecture and better supply management. [1]

## Circuit / controls

- High-gain silicon fuzz.
- **STARVE** control.
- Added boost circuits to each section/cut.
- Internal trim pots set maximum output of the individual stages.
- Power filtering added.
- True bypass.
- Internal Faraday shielding. [1]

## Transistor

- **Technology:** High-gain silicon fuzz.
- Exact transistor part number is not published.

## Diode / clipping

- Exact clipping-device arrangement is not documented in the reviewed V2 source.

## Construction

The documented V2 build includes:
- Neutrik 1/4-inch jacks.
- Vintage Philips, K40Y-9 and Sprague Vitamin Q paper-in-oil capacitors.
- 22 AWG cloth wiring.
- Black faceplate with natural English-ash frame.
- Internal Faraday shielding. [1]

## Power

- The reviewed source confirms the starve and added power-filtering architecture but does not publish a complete standalone current/voltage table in the surviving listing.

## Version history

- **V1 → V2:** Full redesign.
- Added power filtering, boost circuitry, starve control and internal output trims are explicit V2 changes. [1]

## Sound

V2 retains the aggressive high-gain silicon basis while providing more controlled movement between drive stages. Starve and per-stage boost/trim functions broaden the available compression and saturation textures compared with the original Fuzz Controller. [1]
