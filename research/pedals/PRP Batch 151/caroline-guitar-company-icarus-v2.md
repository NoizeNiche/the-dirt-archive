# Caroline Guitar Company Icarus V2

- **Builder:** Caroline Guitar Company
- **Catalog type:** Distortion / Fuzz / Overdrive
- **Catalog identity:** Icarus V2
- **What this pedal is:** A buffer/booster/overdrive based on Caroline's Parabola and Météore preamp concepts, using multiple gain stages and the company's Russian-germanium-voiced clipping approach.
- **Colorways:** Standard production finishes are documented; limited Icarus V2 runs include alternate cosmetic and component variants.
- **Versions:** Icarus V2 is a legacy version of the Icarus family. A later V2.1 limited run was documented with hybrid germanium/silicon clipping.
- **Version changes:** Documented V2 variants include an early run using D310 diodes and a limited V2-R2/USA finish using D9-family Russian germanium diodes alongside silicon. The Alpha Gain designation is also listed by Caroline as a model option, while conversion of older units to Alpha Gain is documented as a modification rather than a baseline version.
- **Transistor type:** Not documented in the reviewed primary product material.
- **Diode type:** Russian germanium diodes are part of the documented Icarus voicing; specific V2 runs are identified with D310 or D9-family parts.
- **Controls / switching:** GAIN, HIGHS, and OUTPUT are documented for V2; internal switching provides buffered or true-bypass operation. OUTPUT can provide a clean boost even with gain reduced.
- **Power:** 9V DC.
- **Sound:** Icarus combines low-gain clean boost behavior with richer overdrive and a pronounced upper-range control, retaining clarity while adding Russian-germanium-style sweetness. The design is intended to work both as a standalone drive and as a signal-shaping/boost stage.
- **Research confidence:** High for the architecture, controls, bypass options, and documented component variants; medium for the exact chronology of individual V2 runs.
