# Caroline Guitar Company Haymaker

- **Builder:** Caroline Guitar Company
- **Catalog type:** Overdrive
- **Catalog identity:** Haymaker
- **What this pedal is:** A dynamic drive built around a quad op-amp and a three-way mode-switched asymmetric clipping network. Caroline developed it as a standalone version of the preamp/overdrive idea that grew out of the Kilobyte delay.
- **Colorways:** The standard production Haymaker is documented in leaf green/yellow; limited factory runs included matte black with mint-green lettering, textured gold, and black/silver editions. Custom artwork editions also existed.
- **Versions:** Original production model, made approximately 2014-2018, plus documented limited color/component runs.
- **Version changes:** Mode A uses soft clipping, Mode B removes the clipping diodes so the op-amp itself is overdriven, and Mode C uses hard clipping. The gold run documented a D9E Russian germanium diode substitution in the asymmetric clipping network; the black/silver run also received gain and D9E changes.
- **Transistor type:** Not documented as a defining transistor stage in the reviewed manufacturer material.
- **Diode type:** Standard diode type not documented; a D9E Russian germanium diode is documented for the 2016 Gold Haymaker and later black/silver special run.
- **Controls / switching:** Three-way mode switch with Caroline's Shape-derived tone architecture; the exact control labels vary in surviving descriptions, so only documented functions are retained here.
- **Power:** Exact power specification not established from the reviewed primary material.
- **Sound:** Haymaker spans transparent crunch, classic overdrive, and high-gain territory while changing feel and EQ response between its three clipping modes. Mode B can become unusually raw and brittle, while Mode C can approach the character of the original Wave Cannon without being an exact clone.
- **Research confidence:** High for circuit architecture, mode behavior, production period, and documented special runs; medium for exact standard color and power details.
