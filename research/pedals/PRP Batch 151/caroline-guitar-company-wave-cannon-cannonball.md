# Caroline Guitar Company Wave Cannon / Cannonball

- **Builder:** Caroline Guitar Company
- **Catalog type:** Distortion / Fuzz / Overdrive
- **Catalog identity:** Wave Cannon / Cannonball
- **What this pedal is:** Caroline's first product, launched in 2010, using a hard-clipping op-amp gain core with a discrete transistor buffer and later special Havoc/custom-artwork implementations.
- **Colorways:** No single stable factory colorway covers the family. Cannonballs were intentionally issued as limited custom-artwork editions, including individually painted examples and other special finishes.
- **Versions:** Wave Cannon v1; Cannonball limited/custom editions and related special runs.
- **Version changes:** Cannonball editions retained the original Wave Cannon platform while adding artwork and, in documented cases, special tweaks/HAVOC arrangements. The original and MKII are separate designs.
- **Transistor type:** A discrete transistor buffer is documented, but the exact transistor part number is not.
- **Diode type:** Exact diode type not documented in the reviewed manufacturer material.
- **Controls / switching:** Wave Cannon uses the original drive/tone architecture with HAVOC appearing on documented variants. Exact labels vary across surviving custom examples.
- **Power:** Exact standard specification not established from the reviewed manufacturer material.
- **Sound:** The original Wave Cannon is a dynamic, responsive booster/overdrive/distortion with a thick classic hard-clipped character. Custom Cannonballs can add stranger feedback/HAVOC behavior without being treated as a wholly separate base circuit.
- **Research confidence:** High for the lineage and circuit architecture; medium for individual Cannonball control layouts and color chronology.
