# BIXONIC - AXENTRIX A1

## PRP identity
- **Builder:** BIXONIC
- **Catalog type:** Distortion / Fuzz / Overdrive

## Research
AXENTRIX A1 is a digital multi-distortion pedal derived from BIXONIC's EXPANDORA lineage. It provides four selectable drive modes, Crunch, Over Drive, Distortion and Fuzz, plus an Accent control for dynamic-range expression, three-band EQ, selectable true or buffered bypass, guitar/bass instrument selection and three user memories. BIXONIC describes its DREP processing as controlling both expansion and compression of the input dynamic range.

## Versions
- **Limited Edition:** BIXONIC currently lists a limited-edition A1 with the same core four-mode architecture and memory functions.

## Sound
A1 moves from transparent crunch and overdrive into full distortion and a dedicated fuzz mode. Its Accent/DREP system emphasizes picking dynamics, so the pedal can move from smoother sustain toward sharper, more percussive attack behavior.
