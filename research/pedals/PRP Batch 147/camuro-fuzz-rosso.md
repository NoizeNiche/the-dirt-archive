# Camuro Fuzz Rosso

- **Builder:** Camuro
- **Catalog type:** Fuzz
- **Catalog identity:** Fuzz Rosso
- **Colorways:** Red, gray, and silver examples are documented across Camuro's official product and demonstration material.
- **Versions:** Camuro documents an initial prototype, a limited special version with two toggle switches, and a Germanium Transistor special version. A silver special version is also listed.
- **Version changes:** The documented special versions add factory features rather than establishing a single numbered V1/V2 sequence. The Germanium version explicitly changes the transistor type to germanium; the gray/silver special versions use the FAT and transistor-switching feature set described by Camuro.
- **Transistor type:** The base Fuzz Rosso transistor type is not documented in the reviewed sources. A dedicated Fuzz Rosso Ge Tr version explicitly uses a germanium transistor.
- **Diode type:** Not documented in the reviewed sources.
- **Controls / switching:** The special version is documented with FAT and transistor selection via two toggle switches. Exact base-model control labeling was not confirmed in the reviewed text.
- **Sound:** Camuro describes Fuzz Rosso as a fine-grained, high-quality fuzz that pairs well with tube amplifiers. Its builder material also presents it as a fuzz-booster style circuit that can add dirt to a clean amplifier or flavor an already-crunchy tube amp.
- **Research confidence:** High for the documented special versions and general function; medium for the distinction between the various early/special builds because the product archive mixes prototype and limited-edition entries.

## Sound

Camuro's product archive confirms several distinct Fuzz Rosso forms: an initial prototype, a limited two toggle special version, a Germanium Transistor version, and a silver special version. Camuro specifically describes the special two toggle units with FAT and selectable transistor behavior. The Germanium Transistor version explicitly uses a germanium transistor.
Camuro also describes Fuzz Rosso as a fine grained fuzz that works well with tube amplifiers and documents it as a fuzz/booster style design that can be used on a clean amp or as a flavoring stage into an already crunchy tube amp.
