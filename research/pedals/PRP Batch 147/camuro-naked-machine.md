# Camuro Naked Machine

- **Builder:** Camuro
- **Catalog type:** Distortion / Overdrive
- **Catalog identity:** Naked Machine
- **Colorways:** The reviewed official and interview material shows a black enclosure with a metal faceplate; no formal colorway catalog was confirmed.
- **Versions:** Initial/prototype builds preceded a limited production run. Camuro also documents test units with different external layouts.
- **Version changes:** Camuro states that the production unit retained the same circuit specification as the early unit while some prototype/test units had different knob sizes, layouts, or nameplates. Ten production units were made, and the run sold out in 2014.
- **Transistor type:** Not documented in the reviewed sources.
- **Diode type:** Not documented in the reviewed sources.
- **Controls / switching:** The enclosure contains independent overdrive and distortion sections in the signal order guitar -> overdrive -> distortion -> amp. The overdrive uses a vintage JRC4558D op amp with an exposed TS-style character; the distortion uses an LM308N op amp.
- **Sound:** Naked Machine is a limited signature preamp/overdrive designed for Yutaka Aoki. His documented usage kept the distortion section relatively clean as a preamp and used the overdrive section for added gain, giving the combined pedal a staged, amp-front-end-oriented character.
- **Research confidence:** High for circuit devices, signal order, production quantity, and documented prototype/production differences.
- **Sources checked:**
  - https://camuro.co.jp/pedals/nakedmachine
  - https://www.cloudchair.net/guitar/yutaka-aoki-naked-machine-interview/
