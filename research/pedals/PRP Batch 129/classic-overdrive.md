# Build Your Own Clone — Classic Overdrive

## PRP identity
- **Builder:** Build Your Own Clone
- **Catalog type:** Overdrive
- **Identity:** DIY recreation of the Ibanez TS-808 Tube Screamer.

## What this pedal is
Classic Overdrive is BYOC's direct TS-808-style kit. Effects Database describes it as a straightforward recreation using the original JRC4558D op amp and true bypass. [1]

## Colorways
- DIY kit; finished enclosure appearance depends on the builder.

## Versions and factory options
- JRC4558D
- Tone
- Level
- Drive
- True bypass
- TS-808 circuit specification [1]

The preserved build instructions also list 1N4148 clipping diodes and several transistor options in the kit. [2]

## Version changes
No numbered BYOC revision was verified.

## Transistor
- Build options listed in the instructions include MPSA18, 2N5088, 2N3904 or 2N2222. These are kit options, not a single fixed production part. [2]

## Diode
- **Type:** Silicon.
- **Device:** 1N4148. [2]

## Sound
Classic Overdrive is intended to reproduce the familiar focused Tube Screamer response without extra voicing switches. BYOC's stated emphasis is a direct TS-808 recreation with the JRC4558D and true bypass. [1]
