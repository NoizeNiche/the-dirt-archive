# Build Your Own Clone — Fuzz Clone

## PRP identity

- **Builder:** Build Your Own Clone
- **Catalog type:** Fuzz
- **Identity:** DIY recreation of the original Dallas Arbiter Fuzz Face circuit.

## What this pedal is

Fuzz Clone is built to the original Dallas Arbiter Fuzz Face specifications with modern power and building conveniences. The kit includes matched silicon BC108 and germanium AC127 transistor sets so builders can choose germanium, silicon or hybrid combinations. [1]

## Colorways

## Versions and factory options

- Silicon BC108 set
- Germanium AC127 set
- Hybrid transistor combinations
- Gold-plated transistor sockets
- Internal bias trimpot
- Negative-ground power configuration [1]

## Sound

Fuzz Clone preserves the basic Fuzz Face response while allowing the builder to explore different transistor combinations and bias settings. The bias trimpot can move the sound from smoother, sustaining fuzz toward raspier or gated behavior. [1]
