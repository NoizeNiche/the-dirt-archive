# AJcustom — Distortion

## PRP identity
- **Archive parent:** Distortion

- **Identity:** A modified BOSS DS-1-based distortion with selected component values and true bypass. [1]

## What this pedal is
AJcustom describes this pedal as a modified BOSS DS-1 that keeps the familiar DS-1 feature set while changing component selection and adding true bypass. The stated result is a denser, richer sound in a compact metal enclosure with etched artwork. [1]
