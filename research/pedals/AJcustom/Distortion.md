## What this pedal is
AJcustom describes the pedal as a modified BOSS DS-1 that retains the familiar DS-1 feature set while using selected component values and adding true bypass. The manufacturer description attributes a denser, richer character to those changes rather than presenting the pedal as a wholly different circuit family. [1]

The documented construction uses a heavy metal enclosure with etched artwork and supports either a stabilized power supply or a 9 V 6F22 battery. [1]
