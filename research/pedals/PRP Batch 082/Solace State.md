# Big Game Pedals - Solace State

## PRP identity
- **Archive parent:** Solace State
- **Builder:** Big Game Pedals
- **Catalog type:** Distortion
- **Identity:** Big Game Solace State, a preamp/distortion derived from the builder's CVLT Preamp work.

## What this pedal is
Effects Database describes Solace State as a derivative of the limited CVLT Preamp, with lineage to the **Peavey F800B-style solid-state preamp** concept. The pedal combines a clean preamp/boost mode with a distortion mode and two-band EQ.

## Controls
- **Volume**
- **50 Hz Bass:** Bass boost/cut.
- **5 kHz Treble:** Treble boost/cut.
- **Clean Boost/Preamp / Distortion** mode switch.
- An internal pre-gain trim is documented in builder discussion.

## Circuit / architecture
- Internal voltage conversion raises operating voltage to approximately **24V**.
- Reported lineage: Peavey F800B / CVLT-style solid-state preamp.
- Exact transistor, op-amp and diode part numbers were not established.

## Sound
The documented architecture ranges from clean preamp/boost behavior to aggressive solid-state distortion, with substantial low-frequency headroom and two-band EQ shaping.
