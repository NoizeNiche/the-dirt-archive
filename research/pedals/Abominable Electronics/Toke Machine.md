# Abominable Electronics — Toke Machine

## PRP identity
- **Archive parent:** Toke Machine
- **Builder:** Abominable Electronics
- **Catalog type:** Fuzz
- **Identity:** Thick fuzz with footswitchable octave-up and diode-clipping modes.

## What this pedal is
Toke Machine is a very thick, loud fuzz with three primary controls and a second footswitch for a vintage-style octave-up overtone. A Destroy toggle adds diode clipping for more volume and intensity, while the current version uses relay-based soft-touch switching. [1]

## Colorways
- Surviving examples use **custom screen-printed/illustrated artwork** rather than one fixed enclosure color.
- A current throwback-art version is explicitly described as the same pedal with different artwork. [2]

## Versions and factory options
### Toke Machine production
- Volume
- Tone
- Fuzz
- Destroy clipping toggle
- Octave footswitch
- true bypass
- relay soft-touch switching
- top-mounted jacks [1]

### Throwback Art
The Throwback Art version is explicitly documented as the **same Toke Machine** with alternate artwork, so it is treated as an artwork variant rather than a circuit revision. [2]

## Version changes
The clearest documented change is cosmetic artwork, while later production uses relay soft-touch switching. No numbered circuit revision was verified.

## Transistor
- **Technology:** Solid-state fuzz.
- **Exact transistor/device:** Not publicly documented.

## Diode
- **Type:** Diode clipping is part of the Destroy function, but the exact production diode type is not published. [1]
- **Exact part:** Unknown.

## Sound
Toke Machine is voiced for a huge, thick fuzz sound with an overtone-rich octave-up mode that can make lead lines jump out. The Destroy function adds extra clipping and volume, pushing the already-heavy fuzz toward a louder, more compressed and aggressive texture. [1]
