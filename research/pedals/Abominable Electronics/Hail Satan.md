# Abominable Electronics — Hail Satan

## PRP identity
- **Archive parent:** Hail Satan
- **Builder:** Abominable Electronics
- **Catalog types:** Distortion / Fuzz
- **Identity:** Original Abominable Electronics Big Muff-derived Hail Satan circuit.

## What this pedal is
Hail Satan is Abominable Electronics' heavily modified Big Muff-style fuzz/distortion. The builder added a Mids control and a second footswitch that changes the clipping from the standard **silicon diodes** to **5 mm red LED diodes**, making the alternate mode louder and crunchier. [1][2]

## Colorways
- Surviving examples use multiple graphic/finish treatments, including standard black/etched or printed designs and limited artwork editions.
- Abominable has repeatedly changed enclosure colors and artwork, so these are not treated as circuit revisions unless the builder explicitly says otherwise. [3]

## Versions and factory options
### Original Hail Satan
- Volume
- Tone
- Sustain
- Mids
- switchable clipping mode
- silicon diodes in the standard mode
- 5 mm red LED clipping in the alternate mode
- true bypass [1][2]

### Hail Santa / special artwork editions
Abominable has sold limited artwork versions using the same Hail Satan circuit, including a Hail Santa splatter edition. The builder explicitly says the Hail Santa version uses the same circuit as Hail Satan with the added Mids control. [3]

## Version changes
The core documented feature set is stable across the standard Hail Satan family, while artwork and special-edition enclosure treatments vary. The key circuit feature is the switchable silicon-versus-red-LED clipping. [1][3]

## Transistor
- **Technology:** Solid-state Big Muff-derived fuzz/distortion.
- **Exact transistor/device:** Not publicly documented.

## Diode
- **Type:** **Silicon diodes and 5 mm red LED diodes**, selectable by footswitch. [1][2]
- **Exact diode/device:** The factory documents the diode types but not individual part numbers.

## Sound
Hail Satan takes the thick Muff-style wall of fuzz and pushes it toward a rougher, crunchier voice with more mids available. The red-LED mode is louder and more aggressive than the standard silicon clipping, making the second footswitch function as a tonal and gain jump rather than simply an on/off feature. [1][2]
