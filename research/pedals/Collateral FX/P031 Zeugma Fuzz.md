# Collateral FX - P031 Zeugma Fuzz

## PRP identity
- **Archive parent:** P031 Zeugma Fuzz
- **Catalog identity:** P031 Zeugma Fuzz
- **Builder:** Collateral FX
- **Catalog type:** Fuzz
- **Identity:** Collateral FX Zeugma, a Zonk Machine MkI-derived fuzz using matched germanium transistor sets.

## What this pedal is
Collateral FX lists P031 as the **Zeugma Fuzz**. Build documentation by the builder identifies Zeugma as a Zonk Machine MKI project, and a current Reverb listing identifies the finished pedal as a Collateral FX Zeugma / Zonk Fuzz. [1][2][3]

## Colorways
The current Reverb example is finished in a hammered blue/aqua enclosure, but that listing represents one individual build rather than a documented complete factory colorway sequence. The archive therefore records the finish as an example, not a universal factory colorway. [2]

## Versions and factory options
- Zonk Machine MKI-inspired fuzz architecture.
- Germanium transistor builds with device selection/matching.
- Builder-documented component examples include Toshiba 2SB54, GT310B, and Texas Instruments 2N404 in one MKI build. [1]
- Other documented Zeugma builds use vintage combinations such as Tungsram AC125, Toshiba 2SB54, and Texas Instruments 2N404. [3]
- 1/2W carbon-composition resistors and vintage capacitors are used in the builder's documented builds. [1]

## Version changes
The available build documentation shows transistor selection varying between individual builds rather than a fixed numbered revision history. Exact installed devices should therefore be treated as build-specific unless a particular unit is documented. [1][3]

## Transistor
Documented Zeugma builds use **three germanium transistors**. One builder-posted MKI build specifies Toshiba 2SB54 for Q1, GT310B for Q2, and Texas Instruments 2N404 for Q3; another documented build uses Tungsram AC125, Toshiba 2SB54, and Texas Instruments 2N404. These examples show that the transistor set is not necessarily identical across units. [1][3]

## Diode
No exact diode specification was established from the available builder and product documentation.

## Sound
The builder describes the completed Zeugma MKI build as sounding strong, while the Zonk/MKI reference places the circuit in the vintage germanium fuzz family. The archive avoids assigning a fixed modern voicing beyond that circuit lineage because the available documentation shows build-to-build transistor variation. [1][2]
