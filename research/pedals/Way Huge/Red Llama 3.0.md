- **Identity:** Way Huge Smalls Red Llama, model WM23, the compact anniversary-era return of the Red Llama family.

## What this pedal is
The WM23 Smalls Red Llama is the compact return of the Red Llama Overdrive. Jim Dunlop identifies the original RL2 as Way Huge's first production pedal, introduced in 1992, and describes the WM23 as a smaller-format return intended to reproduce the harmonic, touch-sensitive character of the earlier Red Llama.

## Versions and factory options
### Original Red Llama / RL2
- First Way Huge production pedal, introduced in **1992**.
- Harmonic overdrive with a crunchy tweed-style character.

### WHE-206 25th Anniversary
- **1,000 pieces worldwide**.
- Smaller pedalboard-friendly housing.
- Added **Hi-Cut** control.

### WM23 Smalls Red Llama
- Compact anniversary-era version.
- Controls: **Volume** and **Drive**.
- Hardwire-relay bypass.
- 9V battery or compatible external supply.

## Version changes
- RL2 established the 1992 original.
- WHE-206 added Hi-Cut and limited-edition 25th-anniversary treatment.
- WM23 brought the Red Llama back in the smaller Smalls enclosure with the two-knob external control layout.

## Sound
Way Huge describes the Red Llama as a harmonic overdrive capable of moving from soft, touch-sensitive drive into more aggressive, fuzz-like saturation. The WM23 is intended to retain the warm, crunchy tweed-like character of the original in a compact enclosure.
