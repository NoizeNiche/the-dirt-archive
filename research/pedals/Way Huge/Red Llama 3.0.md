# Way Huge — Red Llama 3.0

## PRP identity
- **Archive parent:** Red Llama 3.0
- **Builder:** Way Huge
- **Catalog type:** Overdrive
- **Identity:** Way Huge Smalls Red Llama, model WM23, the compact 30th-anniversary-era return of the Red Llama circuit.

## What this pedal is
The WM23 Smalls Red Llama is the compact return of Jeorge Tripps' Red Llama Overdrive. Dunlop/Way Huge identifies the original RL2 as Way Huge's first production pedal, introduced in 1992, and describes the WM23 as a compact recreation of the 1990s-era sound.

## Colorways
- **Smalls enclosure** with the Way Huge Red Llama artwork.
- The archive treats finish/artwork differences as variants unless the underlying product changes.

## Versions and factory options
### Original Red Llama / RL2
- First Way Huge production pedal, introduced in **1992**.
- Known for harmonic overdrive associated with a pushed tweed-amplifier character.

### WHE-206 25th Anniversary Red Llama
- Limited to **1,000 pieces worldwide**.
- Smaller pedalboard-friendly enclosure.
- Added **Hi-Cut** control to the original compact control layout.

### WM23 Smalls Red Llama
- Compact **30th-anniversary-era** return.
- External controls: **Volume** and **Drive**.
- Hardwire-relay bypass.
- Powered by a 9V battery or compatible Dunlop/MXR power supply.

## Version changes
- RL2 established the original 1992 Red Llama.
- WHE-206 added the Hi-Cut control and 25th-anniversary edition treatment.
- WM23 returned the model in an even more compact Smalls enclosure while retaining the core Red Llama character.

## Sound
Way Huge describes the Red Llama as producing harmonic overdrive ranging from soft, touch-sensitive tones to more aggressive, fuzz-like saturation. The WM23 is intended to preserve the warm, crunchy tweed-like character of the original while fitting into a modern compact enclosure.
