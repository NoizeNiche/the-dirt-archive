## What this pedal is
The Blower Box Deluxe is a bass distortion derived from the original Blower Box. IdiotBox redesigned it for a tighter, more mid-focused response and added a parallel clean path with a sweepable low-pass filter.

## Colorways
- Documented finishes include **Green and Black**, **Purple and Black**, and **Pink and Black**.
- Finish options are treated as enclosure variants, not separate circuits.

## Versions and factory options
- **DIR:** direct/clean-signal volume.
- **PASS:** direct-signal low-pass filter, approximately 150Hz to 10kHz.
- **HIGH:** distortion high-frequency cut/boost.
- **LOW:** distortion low-frequency cut/boost.
- **DIST:** distortion intensity.
- **VOL:** distortion volume.
- True bypass.
- 9V, 12V, or 18V DC operation.
- 2.1mm center-negative Boss-style power input.
- Current draw: 6mA.
- 125B-size enclosure, approximately 4.7 x 2.6 x 1.5 inches.
- Made in the USA.

## Version changes
- The Deluxe version adds the parallel clean blend and low-pass filter while tightening the original Blower Box's voicing.
- The archive does not merge Deluxe features into the original Blower Box record.

## Sound
The Blower Box Deluxe is designed for heavy bass distortion while retaining low-end definition. The clean path can be blended underneath the distortion, and PASS allows the clean contribution to be filtered from deep lows through higher frequencies.
