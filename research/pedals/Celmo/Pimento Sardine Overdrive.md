# Celmo — Pimento Sardine Overdrive

## PRP identity
- **Archive parent:** Pimento Sardine Overdrive
- **Builder:** Celmo
- **Catalog type:** Overdrive
- **Identity:** Handcrafted French analog overdrive using E.A.S.E. (Enhanced Analog Sag Emulator) and a three-position Color switch. [1][2]

## What this pedal is
Premier Guitar describes Pimento Sardine as a hand-crafted French overdrive built around **E.A.S.E.**, Celmo's enhanced analog sag emulator. Effects Database independently classifies it as an analog overdrive using the same system. [1][2]

## Controls
- **DRIVE:** Overdrive amount.
- **VOLUME:** Output.
- **COLOR:** Three-position voicing switch.
- Exact control naming/order can vary by source presentation, but the three-control function set is documented. [1][3]

## Circuit / topology
- Analog overdrive.
- E.A.S.E. emulates the dynamic supply sag associated with a tube amplifier under load.
- The builder's design is intended to remain responsive to guitar-volume and playing dynamics. [1]

## Sound
E.A.S.E. is designed to make the overdrive respond more like a power-amp circuit under changing load. Premier Guitar describes the pedal as capable of boost and saturated crunch, with strong response to guitar-volume changes; the Color switch changes the voicing rather than acting as a conventional full-range EQ. [1][2]
