# Silktone — Fuzz

## PRP identity

- **Archive parent:** Fuzz

- **Identity:** Silktone Fuzz, the original/discontinued model.

## What this pedal is

The original Silktone Fuzz is a germanium fuzz using a classic Fuzz Face/TB1.5-style topology, an onboard pickup simulator, an Active Bias Monitor, and a cleanup control. Silktone later developed the separate **Fuzz+** as an updated model with additional tone controls and a second footswitch.

## Colorways

Silktone's documented original Fuzz finishes include **Classic Black**, **Turquoise**, and **Limited Anthrax**.

## Versions and factory options

The archive treats **Fuzz** and **Fuzz+** as separate catalog identities. The original Fuzz uses a single effect footswitch and the Classic/Raw switch. Fuzz+ adds the second footswitch and additional tone shaping.

## Controls

- **Volume**
- **Fuzz**
- **Cleanup**
- **Bias**
- **Classic / Raw** switch

The Active Bias Monitor provides the bias readout.

## Sound

Silktone describes the original Fuzz as a flexible germanium fuzz ranging from gated and vintage textures through fat, sticky fuzz. The cleanup control can move the pedal toward lighter overdrive or boost behavior, while Classic/Raw changes the bass filtering and bias relationship.

## Power

The original Fuzz uses a **positive-ground** supply arrangement and requires an isolated 9V DC supply when powered from a brick. Daisy chaining is not recommended.
