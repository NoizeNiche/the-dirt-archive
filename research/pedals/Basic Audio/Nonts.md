# Basic Audio — Nonts

## PRP identity
- **Archive parent:** Nonts
- **Builder:** Basic Audio
- **Catalog type:** Fuzz
- **Identity:** Silicon Buzzaround-derived fuzz that evolved through multiple documented iterations, with the later configuration exposing Volume, Tone, Fuzz, Starve and Bias. [1][2]

## What this pedal is
Basic Audio's Nonts is a silicon interpretation of the Baldwin-Burns Buzzaround. The defining later controls make bias and supply starvation externally adjustable. [1][2]

## Controls
- **VOLUME**
- **TONE**
- **FUZZ**
- **STARVE**
- **BIAS**
The five-control configuration is the mature documented version; earlier versions had fewer/different controls. [1][2]

## Circuit lineage
- **Primary reference:** Baldwin-Burns Buzzaround.
- **Technology:** Silicon.
- The implementation is an interpretation, not an untouched historical component clone.

## Transistor
- **Technology:** Silicon.
- Exact production transistor part number is not publicly documented.

## Diode / clipping
- Exact clipping-device type and part number are not publicly documented.

## Power
- **9V center-negative** with battery support. [1]

## Version history
Guitar Pedal X documents multiple iterations before the later five-control presentation. The archive retains this as development history without assigning undocumented component changes to each step. [2]

## Sound
Nonts preserves the lively, harmonically rich Buzzaround character while Starve and Bias can push the circuit toward compressed, gated, synthetic and supply-starved textures. [1][2]
