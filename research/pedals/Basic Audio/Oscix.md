# Basic Audio — Oscix

## PRP identity
- **Archive parent:** Oscix
- **Builder:** Basic Audio
- **Catalog type:** Fuzz
- **Identity:** Basic Audio's Germanium Fuzz Face / Fuzz Factory-derived oscillating fuzz.

## What this pedal is
Oscix combines a Germanium Fuzz Face/Fuzz Factory-style core with extensive control over bias, voltage, tone, gain and oscillation behavior. Basic Audio specifically describes free oscillation and controlled-envelope behavior, with a very large range of possible settings. [1][2]

## Colorways
- A **green/blue distressed enclosure with a black geometric faceplate** is documented in Basic Audio's official photographs.
- Basic Audio shows multiple Oscix examples/angles on the product page, supporting that this is a real production model rather than a single one-off prototype. [1]

## Versions and factory options
### Oscix production
The documented configuration includes:
- Level
- Starve
- Fuzz
- Gate
- Pinch
- OSC
- Vintage toggle
- FAT toggle [1][2]

The circuit provides both self-oscillating sounds and more controlled envelope behavior, with the controls interacting strongly enough to create a very large range of responses. [1]

No numbered factory revision was verified.

## Sound
Oscix can move from conventional dirty fuzz into controlled squeal, self-oscillation and envelope-like behavior. Bias, starve, gate and pinch controls can make the circuit tighten, choke, sputter or break into sustained electronic tones, making it one of the more intentionally unstable Basic Audio designs. [1][2]
