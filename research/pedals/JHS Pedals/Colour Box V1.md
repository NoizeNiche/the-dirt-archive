# JHS Pedals - Colour Box V1

## PRP identity

- **Builder:** JHS Pedals
- **Pedal:** Colour Box V1
- **Catalog type:** Preamp / Overdrive / Distortion / Fuzz
- **Identity:** First-generation Colour Box direct-in preamp/distortion device.

## What this pedal is

JHS identifies the Colour Box concept as a studio-grade preamplifier, EQ and distortion generator developed in 2012 and released in 2014. JHS's history page records the V1 debut at Winter NAMM 2014.

## Version history

- **V1:** Smaller enclosure, no EQ Shift knobs, seven knobs total.
- **V2:** Larger enclosure, ten knobs, Hi/Lo switch, phantom-power support and output transformer.

## Circuit / controls

JHS's current V2 documentation describes the V1's core function as a multi-stage preamp whose gain can move from clean level enhancement through overdrive, distortion and fuzz. The V1 specifically used seven knobs and lacked the V2 EQ-shift controls.

## Sound / use

The Colour Box was designed to reproduce direct-in/console-style guitar and other instrument recording textures and can move into intentional overdrive, distortion and fuzz.
