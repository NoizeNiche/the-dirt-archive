# Browne Amplification — The Carbon - Overdrive

## PRP identity
- **Builder:** Browne Amplification
- **Catalog type:** Overdrive
- **Identity:** Naming variant of Browne's standalone Carbon product.

## What this pedal is
Browne's current manufacturer page names the product **The Carbon**. The tracker also contains **The Carbon - Overdrive** as a separate naming form; both records point to the same manufacturer product page and should be treated as a catalog-naming normalization issue rather than silently assumed to be different hardware. [1]

## Colorways
The current page shows blue and black finishes. [1]

## Versions and factory options
- Standalone Protein blue-side circuit
- V2 three-position hi-cut
- Subtle Cut / OG Carbon / More Cut positions
- Soft switching
- Adjustable startup state [1]

## Version changes
V2 adds the hi-cut variations around the original Carbon setting. [1]
