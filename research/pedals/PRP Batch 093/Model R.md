# BJFE / BJF Electronics - Model R

## PRP identity
- **Builder:** BJFE / BJF Electronics
- **Catalog type:** Distortion

## Research
A BJFE distortion built for the 2006 ToneFest in Chicago, with 40 made of a possible 99. The historical reference says it was originally designed with a Les Paul and is a distortion-oriented counterpart to the Dynamic Orange Overdrive, while experimentation with it influenced later EQ changes to the Mighty Red Distortion.
