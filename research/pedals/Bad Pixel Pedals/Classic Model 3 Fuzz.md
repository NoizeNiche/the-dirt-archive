# Bad Pixel Pedals - Classic Model 3 Fuzz

## PRP identity
- **Archive parent:** Classic Model 3 Fuzz
- **Builder:** Bad Pixel Pedals
- **Catalog type:** Fuzz
- **Identity:** Bad Pixel's Classic Series Model 03, a BC108 silicon Fuzz Face-style circuit with external bias.

## What this pedal is
The Classic BC108 Face page describes a classic Fuzz Face configuration built in a compact Classic Series Hammond enclosure. The circuit uses a selected pair of BC108 silicon NPN transistors and adds an external bias control for broader shaping.

## Colorways
- The documented Model 03 unit uses a **brown/bronze-toned textured Classic Series finish**.
- No complete factory colorway chronology was verified.

## Versions and factory options
### Classic Model 3 / Classic BC108 Face
- External bias control
- Pair of selected BC108 silicon NPN transistors
- NOS USSR capacitors
- 1/2-watt carbon composition resistors
- 1590C Hammond enclosure
- Neutrik jacks
- Handmade Classic Series construction

## Version changes
No numbered production revision beyond the Model 03 designation was verified in the checked sources.

## Transistor
- **Technology:** Silicon Fuzz Face-style fuzz.
- **Documented devices:** Pair of **BC108 silicon NPN** transistors, selected for each pedal.

## Diode
- **Exact clipping/protection arrangement:** Not publicly documented in the checked sources.

## Sound
The builder describes a broad fuzz range controlled by the external bias, from very saturated settings toward the familiar classic Fuzz Face response. Like the other Bad Pixel fuzzes, it is intended to clean up substantially as the guitar volume is reduced.
