# Bad Pixel Pedals — Classic Model 3 Fuzz

## PRP identity
- **Archive parent:** Classic Model 3 Fuzz
- **Builder:** Bad Pixel Pedals
- **Catalog type:** Fuzz
- **Identity:** Classic Series **Model 03**, a silicon Fuzz Face-style fuzz using a selected pair of BC108 NPN transistors and external Bias. [1][2]

## What this pedal is
Model 03 is the Classic Series silicon Face configuration. Bad Pixel pairs a classic Fuzz Face-style topology with modern point-to-point construction and an external Bias control. [1]

## Controls
- **Fuzz**
- **Volume**
- **External Bias**
- True bypass. [1][2]

## Transistor
- **Technology:** Silicon NPN.
- **Documented devices:** **2 × BC108**, selected for each pedal. [1]
## Diode / clipping
- Exact clipping/protection diode arrangement is not publicly documented.

## Construction / hardware
Classic Series specifications include:
- NOS Soviet capacitors.
- 1/2-watt carbon-composition resistors.
- 1590C Hammond enclosure.
- Neutrik jacks.
- Handmade / handwired in Greece. [2]

## Version history
- Model 03 is a model designation, not a documented electronic revision.
- No later numbered circuit revision established.

## Sound
Bad Pixel describes the external Bias as providing a broad silicon-fuzz range and emphasizes useful cleanup from the guitar volume. [1][2]
