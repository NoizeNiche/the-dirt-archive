# Bad Pixel Pedals - Classic Model 2 Fuzz

## PRP identity
- **Archive parent:** Classic Model 2 Fuzz
- **Builder:** Bad Pixel Pedals
- **Catalog type:** Fuzz
- **Identity:** Bad Pixel's Classic Series Model 02, a Dallas Rangemaster-style germanium treble/full-range booster.

## What this pedal is
The builder's Model 02 page describes a recreation of the 1960s Dallas Rangemaster concept. An input-capacitor selector moves the circuit between treble-boost and fuller-range operation, while an external bias control fine-tunes the single germanium transistor.

## Colorways
- The documented Model 02 uses a **textured hammered-grey Hammond enclosure**.
- No complete factory colorway chronology was verified.

## Version changes
No numbered production revision beyond the Model 02 designation was verified in the checked sources.

## Transistor
- **Technology:** Germanium treble/full-range boost.
- **Documented device:** **GT402I[И]** germanium transistor, stated by the builder to sit around 100 hFE.

## Diode
- **Exact clipping/protection diode:** Not publicly documented in the checked sources.

## Sound
The capacitor selector changes the Model 02 from a classic bright treble boost toward a broader full-range boost. The external bias control provides fine adjustment of the germanium device and is intended to help the pedal push a tube amp into natural breakup.
