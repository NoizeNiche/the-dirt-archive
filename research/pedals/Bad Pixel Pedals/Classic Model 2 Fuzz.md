# Bad Pixel Pedals — Classic Model 2 Fuzz

## PRP identity

- **Archive parent:** Classic Model 2 Fuzz
- **Builder:** Bad Pixel Pedals
- **Catalog type:** Boost
- **Identity:** Classic Series **Model 02**, a Dallas Rangemaster-style germanium treble/full-range booster with external Bias and selectable input capacitance. [1][2]

## What this pedal is

Model 02 is Bad Pixel's interpretation of the 1960s Dallas Rangemaster family. An input-capacitance selector changes the frequency emphasis, while the external Bias adjusts the germanium transistor's operating point. [1]

## Controls / switching

- Input-capacitor selector.
- External **Bias**.
- Single-transistor boost architecture.
- True bypass / modern switching on the documented build. [1][2]

## Transistor

- **Technology:** Germanium.
- **Documented device:** **GT402I[И]** germanium transistor, around **100 hFE** according to the builder. [1]

## Diode / clipping

- This is fundamentally a transistor boost rather than a diode-clipping fuzz.
- Exact protection diode, if any, is not documented.

## Construction / hardware

Classic Series documentation specifies:
- Bakelite point-to-point construction.
- 1590C Hammond enclosure.
- Alpha pot.
- Neutrik jacks.
- NOS Soviet components.
- Handmade in Greece. [1][2]

## Version history

- Model 02 is a model designation.
- No additional numbered electronic revision established.

## Sound

The input-capacitance selector moves between classic treble-boost behavior and a broader full-range response. The external Bias is intended to fine-tune the germanium transistor and its interaction with the amplifier. [1]
