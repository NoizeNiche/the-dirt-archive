# Animals Pedal — PUSH & PULL DISTORTION

## PRP identity
- **Archive parent:** PUSH & PULL DISTORTION
- **Builder:** Animals Pedal
- **Catalog type:** Distortion
- **Identity:** Low-to-medium/high gain British-style distortion voiced for the late-1970s/early-1980s “brown sound,” with a three-knob interface and true-bypass operation.
- **Earlier-name relationship:** Independent Japanese documentation identifies **PUSH & PULL DISTORTION** as the same pedal previously released as **霖**, so the alternate name is retained as an alias rather than a separate circuit identity. [1][2]

## What this pedal is
PUSH & PULL DISTORTION is designed to produce a thick, defined “brown sound” style distortion from a clean amplifier. Animals Pedal emphasizes edge, sustain, legato response, fast picking definition, and chord separation even at heavier gain settings. The pedal can also be used as a boost or preamp by reducing Drive and increasing Level. [1][3]

## Controls
- **LEVEL:** overall output volume.
- **DRIVE:** amount/strength of distortion.
- **TONE:** tone control centered toward the high-frequency range. [1][3]

## Power / electrical specifications
Animals Pedal documentation specifies:
- **Supply:** 9V battery or standard **center-negative DC 9V** adapter.
- **Current draw:** **0.5mA**.
- **Input impedance:** **500kΩ**.
- **Output impedance:** **<2kΩ**.
- **Switching:** true bypass.
- **Dimensions:** approximately 64 × 112 × 50mm including protrusions.
- **Weight:** approximately 381g. [1][2]

Battery guidance requires unplugging the input jack while stored to prevent unnecessary drain. [1]

## Sound
Animals Pedal describes the pedal as producing thick early-1980s brown-sound-style distortion with clear note separation, long sustain, strong edge and useful articulation for legato and fast alternate picking. It can also function as a booster/preamp. [1][3]
