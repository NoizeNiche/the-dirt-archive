# Baroni Lab - GD Drive

## PRP identity
- **Archive parent:** GD Drive
- **Builder:** Baroni Lab
- **Catalog type:** Overdrive
- **Identity:** Germanium overdrive using specially selected and matched germanium components.

## What this pedal is
The GD Drive is an analog germanium overdrive positioned between overdrive and distortion. Baroni Lab's published description emphasizes matched germanium components and a voicing that can move from softer boost drive into saturated lead tones.

## Colorways
- A documented production example is **red** with black/white graphics.
- A documented GD Bender example is **black**.
- No complete factory colorway chronology was verified.

## Version changes
Public listings use both **GD Drive** and **GD Bender Germanium Drive** naming. The available documentation does not establish a reliable numbered revision history, so these names are retained as product-family naming rather than treated as separate numbered versions.

## Transistor
- **Technology:** Germanium gain stages/components.
- **Exact transistor:** Not publicly documented in the checked sources.

## Diode

## Sound
The GD Drive is voiced from softer boost overdrive through fully saturated lead tones with natural harmonic sustain. Baroni Lab and dealer documentation describe it as sweet and creamy, with enough output and gain range to work with both single-coil and humbucker guitars.
