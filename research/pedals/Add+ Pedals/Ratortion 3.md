# Add+ Pedals — Ratortion 3

## PRP identity
- **Archive parent:** Ratortion 3
- **Builder:** Add+ Pedals
- **Catalog type:** Distortion
- **Identity:** Add+ Ratortion 3, an analog overdrive/distortion pedal built in small hand-wired batches in Izmir, Turkey. [1]

## What this pedal is
Ratortion 3 expands the basic Rat-style drive concept into a multi-mode analog overdrive/distortion. Effects Database documents two gain stages, separate OverDrive and Distortion controls, a dedicated footswitch for switching between those modes, a four-position Germanium / Turbo / Classic / MOSFET voicing selector, and a three-way hard / soft / none clipping switch. [1]

## Versions and factory options
### Ratortion 3
- Analog overdrive/distortion
- Two independently controlled gain modes: OverDrive and Distortion
- Four-position voicing selector: Germanium, Turbo, Classic, MOSFET
- Three-way clipping selector: hard, soft, or none
- Volume and Tone controls
- True bypass
- 9V DC center-negative
- Hand-wired small-batch construction
- Suitable for guitar and bass [1]

## Version changes
Effects Database lists Ratortion 3 v2 separately and states that the v2 retains the same functional architecture and control set. No verified component-level change was published in the accessible record, so the archive does not invent one. [1]

## Sound
Germanium mode is documented as producing a more fuzz-like response, while MOSFET provides a more modern distortion character. Classic and Turbo occupy more mid-focused, 1970s-to-1980s-style drive territory, with the clipping switch further changing compression, headroom, and harmonic response. [1]
