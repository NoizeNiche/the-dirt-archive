# Caline - CP-11 Puffer Fuzz

- **Builder:** Caline
- **Catalog type:** Fuzz
- **Primary research sources:** Effects Database exact-model record; Free Stompboxes schematic discussion; Reverb product record.
- **Identity:** The CP-11 Puffer Fuzz is a Caline silicon fuzz with a three-control layout: Fuzz, Tone and Level. Effects Database and retail documentation consistently identify it as the Puffer Fuzz.
- **Colorways:** Blue is documented in retail/source imagery. No verified production colorway catalog was found.
- **Versions:** No numbered factory version verified.
- **Version changes:** No documented production revision was located.
- **Controls:** Fuzz, Tone, Level.
- **Transistor type:** Free Stompboxes documents two 2N3904 NPN transistors in the traced unit.
- **Diode type:** The traced schematic lists a 1N4001 diode; it is not identified there as the clipping element. The archive therefore does not label a dedicated clipping-diode type.
- **Sound description:** Caline describes the pedal as covering vintage through modern fuzz, with the Tone and Fuzz controls shaping the range. Retail and user documentation place it toward the cleaner end of fuzz territory, with lower Fuzz settings capable of crunch-like tones; the traced circuit is described by the forum as a basic silicon Fuzz Face-style topology with an added input rheostat.
- **Circuit / construction:** The traced BOM identifies Fuzz B2K, Tone B100K and Level A100K, with 2N3904 transistors. A later owner reported stable operation at 18V, but the documented retail specification is 9V center-negative and the archive treats 18V use as an owner observation rather than a factory requirement.
- **Power:** Retail documentation states 9V DC center-negative, 30mA, with dimensions about 11.2 x 6.4 x 3.4 cm.
- **Photo status:** Exact-model source imagery located; no local image promoted in this batch.
- **Research confidence:** High for identity, control set and general behavior; high for the traced-unit component list; medium for circuit-family classification because it comes from a third-party trace.
