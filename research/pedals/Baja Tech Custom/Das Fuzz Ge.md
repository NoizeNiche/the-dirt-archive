# Baja Tech Custom - Das Fuzz Ge

## PRP identity
- **Archive parent:** Das Fuzz Ge

- **Catalog type:** Fuzz
- **Identity:** Handmade germanium Fuzz Face-style fuzz with an external KILL/bias control.

## What this pedal is
Das Fuzz GE is a compact handmade germanium fuzz built by Baja Tech Custom. Historical user documentation describes a simple Volume/Fuzz/KILL interface, true bypass, positive-tip power, and a KILL control that shifts the bias toward the reduced-voltage behavior associated with a dying battery.

## Colorways

## Sound
The Germanium Das Fuzz is described as creamy, fat and vintage-voiced, with strong cleanup from the guitar volume control. KILL shifts the bias and can introduce a more strained, dying-battery character, while the underlying fuzz remains rooted in a straightforward Fuzz Face-style response.
