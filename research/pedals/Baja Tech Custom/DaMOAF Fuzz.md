# Baja Tech Custom — DaMOAF Fuzz

## PRP identity
- **Archive parent:** DaMOAF Fuzz
- **Builder:** Baja Tech Custom
- **Catalog type:** Fuzz
- **Identity:** Baja Tech Custom's Big Muff-family fuzz, with the documented Version 1 using Volume, Sustain and Tone and later Deluxe/V2 builds adding additional gain/boost controls. [1][2]

## What this pedal is
Audiofanzine identifies **Da Moaf version 1** as a Big Muff clone with a cleaner, more versatile character than a conventional Muff. The surviving Version 1 review describes a large metal enclosure, three large knobs and 9V battery operation. [1]
The “DaMOAF” name is derived from “Da Mother Of All Da Fuzz” in historical descriptions. [1]

## Controls
### Version 1
- **Volume**
- **Sustain**
- **Tone**
- True bypass.
- 9V battery power only in the documented Version 1 review. [1]

### Deluxe / later variant
- A separate Baja Tech Deluxe description adds a gain/boost stage and **Fine Tune** control.
- The archive keeps those additions as later/Deluxe features rather than attributing them to Version 1. [2]

## Circuit lineage

## Version / build-history notes
- **Da Moaf Version 1:** three-control Big Muff-derived fuzz.

- A complete numbered chronology between all DaMOAF variants is not established.

## Sound
The Version 1 review describes a versatile Muff-style fuzz moving from fat low-frequency sounds to more aggressive tones as Tone is increased, with the Sustain control carrying substantial fuzz range. A separate user report on the later Deluxe describes an unusually huge combined fuzz/distortion sound, but that report is retained only as user experience, not as engineering evidence. [1][3]
