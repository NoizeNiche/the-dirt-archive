## Deep research verification

This pass adds the surviving exact-model Reverb evidence while keeping its provenance distinct from the original UK Baja Tech production record.

### Verified description

The surviving Baja Tech Custom historical catalog lists **Real Tube Overdrive** as a separate product. A Reverb example identifies a **12AX7** tube, a **volume / tone / gain** control set, and a high-voltage tube circuit intended to operate the tube as an active element rather than merely using it as a clipping ornament. The surviving listing describes the example as a **one-of-one custom-built unit made in Ukraine**, so the archive treats those construction details as evidence about that documented unit, not as universal factory specifications for every historical Real Tube Overdrive.

### Verified version references

- Real Tube Overdrive is a distinct historical Baja Tech Custom product.
- At least one surviving example is documented as a one-of-one custom unit from Ukraine.
- No numbered factory revision was established.
