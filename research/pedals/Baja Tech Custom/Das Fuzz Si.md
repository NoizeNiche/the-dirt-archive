# Baja Tech Custom - Das Fuzz Si

## PRP identity
- **Archive parent:** Das Fuzz Si
- **Builder:** Baja Tech Custom
- **Catalog type:** Fuzz
- **Identity:** Silicon Fuzz Face-style fuzz with a KILL control for bias/gain variation.

## What this pedal is
Das Fuzz Si is a tweaked silicon Fuzz Face-style circuit designed to retain some of the warmth associated with germanium while keeping the higher-gain behavior and temperature stability of silicon. The KILL control adds a bias/gain range beyond the basic two-knob version.

## Version changes
The surviving documentation distinguishes the original two-control Das Fuzz from the later Das Fuzz Si with KILL. The Si version retains the basic Fuzz/Volume interface and adds the KILL control for a wider bias/gain response.

## Sound
The circuit aims for a Fuzz Face response with some of the warmth associated with germanium, while silicon devices provide greater temperature stability. The KILL control can move the fuzz from a stock voice through added gain and splatty, dying-battery-style textures.
