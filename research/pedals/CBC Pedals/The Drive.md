# CBC Pedals — The Drive

## PRP identity
- **Archive parent:** The Drive
- **Builder:** CBC Pedals
- **Catalog type:** Overdrive
- **Identity:** Handwired CBC Pedals clone of the Hermida Audio Zendrive circuit.

## What this pedal is
The Drive is a handwired Zendrive clone from CBC Pedals. Reverb listings describe it as an exact-circuit clone, with the same basic four-control layout as the original: Volume, Drive (Gain), Tone, and Presence (Voice). The documented build uses a socketed op-amp and identifies the AD712 as the original chip used in the clone. [1][2]

## Sound
The Drive is voiced as a Zendrive-style overdrive with a four-control interface that allows output, gain, tone, and presence/voice shaping. The builder's surviving description emphasizes a full-range overdrive rather than a narrow fixed-color drive, while the exact-circuit claim means the archive should not assign extra circuit variations that the source does not document.
