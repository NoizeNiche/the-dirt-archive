# Analog Man — Peppermint Fuzz

## PRP identity
- **Archive parent:** Peppermint Fuzz
- **Builder:** Analog Man
- **Catalog type:** Fuzz
- **Introduction:** 2006
- **Identity:** One parent containing the standard Peppermint and the builder's factory **Dark Peppermint** variant.

## What this pedal is
Peppermint Fuzz is a high-gain germanium fuzz developed from Analog Man's broader germanium-fuzz work but voiced to provide more gain and a distinctive Buzz control. Standard controls are Volume, Fuzz and Buzz, with positive-ground germanium circuitry and the compact Analog Man enclosure. [1][2]

## Colorways
- Standard Peppermint examples have the familiar green peppermint finish.
- **Dark Peppermint** is a builder-produced factory variant with a darker finish. It used the same transistor model as the regular pedal but sourced that transistor from a different manufacturer, producing a darker tonal result. Analog Man used a fluorescent-blue coating on the Dark Peppermint enclosure. [1]
- The finish itself is not the reason it is listed as a factory variant; the builder also documents a different transistor source/sonic character.

## Versions and factory variants
### Peppermint Fuzz — standard production
- Volume
- Fuzz
- Buzz
- high-gain germanium transistor stage
- true bypass
- compact enclosure
- positive-ground circuit
- standard unit does not require an LED/power jack unless specified [1]

### Dark Peppermint
- Factory variant using the same transistor model from a different manufacturer.
- Builder describes it as darker sounding than the standard Peppermint.
- Dark Peppermint production ran in small batches and was repeatedly sold out/reintroduced over the years. [1]

## Version changes
The Peppermint line's meaningful documented distinction is the Dark Peppermint factory variant. It is not treated as a separate parent pedal because Analog Man presents it as a Peppermint-family alternate build rather than a wholly new circuit. [1]

## Transistor
- **Technology:** high-gain Germanium.
- Standard and Dark versions use the same nominal transistor model, with Dark Peppermint using a different manufacturer's version of that model.
- Exact current production part number is not specified on the public product page. [1]

## Diode
- **Type:** Unknown.
- No Peppermint-specific diode type or part number was established in the builder material reviewed.

## Sound
Peppermint Fuzz is a high-gain germanium fuzz with a broader and more aggressive range than a restrained vintage fuzz, while the Buzz control provides additional control over its harmonic and frequency character. Dark Peppermint keeps the same basic structure but is intentionally darker, making it the more subdued tonal sibling within the factory variant family. [1][2]
