# Crazy Tube Circuits - Unobtanium Raw

## Research identity
- **Builder:** Crazy Tube Circuits
- **Catalog identity:** Unobtanium Raw
- **Catalog type:** Overdrive / Amp-in-a-Box
- **Identity:** Exact Crazy Tube Circuits Unobtanium Raw.

## What this pedal is
Unobtanium Raw is the limited RAW evolution of the standard Unobtanium. It retains the Klon-style overdrive plus D-style amp section, but changes the K-side clipping implementation and shifts the amp-side voicing toward a glassier, more forceful response.

## K-side controls and changes
- **Gain:** drive amount.
- **Treble:** active high-frequency control.
- **Volume:** output.
- **Stock / OC45 toggle:** selects the standard germanium-diode clipping or the RAW **OC45** germanium-transistor clipping mode.
- **Buffer / True bypass toggle:** selects buffered or relay true bypass.

The OC45 mode uses hand-selected NOS Mullard/Valvo **OC45 germanium transistors** as the alternate clipping element. The standard setting retains the stock germanium-diode clipping.

## D-side
- **Gain:** drive/compression.
- **Emphasis:** pre-drive presence and low-end shaping.
- **Tone:** post-drive high-frequency shaping.
- **Volume:** output.
- **ODS / SSS toggle:** two D-style amplifier voicings.
- The RAW version's D-side is voiced more glassy/punchy than the standard Unobtanium.

## Routing and switching
- Same basic two-section architecture as standard Unobtanium.
- Passive series effects loop between sections.
- Sections can be used independently or together.
- Relay-based true bypass.
- External XT footswitch can select amp voicing.
- Power-up bypass/engage preset function is documented on RAW.

## Power
- 9V DC center-negative only.
- Current draw approximately **83 mA**.
- Internally boosted operating voltage provides additional headroom.

## Versions and factory options
- RAW is a separate limited production edition rather than a cosmetic colorway.
- Crazy Tube Circuits states it uses limited quantities of NOS Mullard/Valvo OC45 parts and does not replace the standard Unobtanium.
- No separate circuit revision beyond the documented RAW changes is established.

## Version changes from standard Unobtanium
- K-side Mod mode is replaced by the OC45 germanium-transistor clipping mode.
- RAW D-side receives a glassier, punchier voicing.
- Power-up bypass/engage preset is documented for RAW.

## Transistor
- **OC45 germanium transistors:** explicitly documented for the RAW clipping mode.
- Exact batch/individual transistor selection beyond the documented Mullard/Valvo OC45 source is not established.

## Diode
- Standard/Stock mode retains the standard germanium-diode clipping.
- Exact diode part number: **not established**.

## Sound
RAW keeps the Klon/D-style core but adds a more compressed, higher-gain OC45 clipping character on the K side and a glassier, punchier amp-side response. External testing describes the RAW as suitable for medium- to high-gain sounds while preserving the dynamic response of the underlying circuits.

## Construction and provenance
