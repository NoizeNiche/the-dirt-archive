## What this pedal is
Stardust is a Blackface-inspired overdrive/amp-in-a-box from Crazy Tube Circuits. The current production version is **Stardust V3**, an all-analog MOSFET design that provides three Blackface-style amplifier voicings while retaining responsive cleanup from the guitar's volume control.

## Current V3 controls
- **Volume:** output level.
- **Tone:** frequency/brightness shaping.
- **Gain:** amount of overdrive.
- Three-way voicing selector:
  - **BSM:** Bassman-style voice.
  - **VLX:** Vibrolux-style voice.
  - **DLX:** Deluxe-style voice.

## Circuit and switching
- All-analog signal path.
- Discrete MOSFET gain stages in V3.
- Soft-click true bypass via relay.
- Internal voltage doubling provides an internally boosted 18V operating rail from an external 9V DC supply.
- Top-mounted jacks.

## Versions and factory options
- The Stardust family includes earlier Blackface versions and the current **V3**.
- Current Crazy Tube Circuits listings identify Stardust V3 as the active production design.
- Cosmetic B-stock/outlet listings are not treated as separate circuit models.

## Version changes
Stardust V3 expanded the earlier Blackface concept to three selectable amplifier voices:
- BSM / Bassman
- VLX / Vibrolux
- DLX / Deluxe

The V3 also uses MOSFET discrete gain stages and internally boosted operating voltage for increased headroom.

## Sound
The current V3 is designed for dynamic Blackface-style overdrive from sparkly cleaner response through crunchy breakup. The three voicings cover a fuller Bassman character, a brighter/cleaner Vibrolux character, and a Deluxe-style low-wattage Blackface voice.

## Construction and provenance
- Handmade in Athens, Greece.
- Current V3 can be used as an amp-in-a-box preamp when paired with suitable downstream speaker simulation.
