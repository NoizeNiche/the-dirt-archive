# OKKO FX — DIRTY DIABLO

## PRP identity

- **Archive parent:** DIRTY DIABLO
- **Builder:** OKKO FX
- **Catalog type:** Distortion / Overdrive
- **Identity:** OKKO FX's Dirty Diablo variant.

## What this pedal is

The Dirty Diablo is a grittier, more saturated development of the Diablo family. The current official OKKO listing identifies the product as **DIRTY DIABLO Dual Raw/Black** and describes it as a variation of the classic Diablo. It retains the Diablo Dual's dual-channel architecture while using an earlier, grittier breakup and more saturation.

## Versions and factory options

- The current official listing is **DIRTY DIABLO Dual Raw/Black**.
- A Raw/White edition is also listed by OKKO as a sold-out Dirty Diablo Dual variation.
- The archive retains the parent identity **DIRTY DIABLO** while preserving the Dual/Raw edition details as the current documented form.

## Version changes

The checked evidence supports the Dirty Diablo as a Diablo-family variant with a more saturated, earlier breakup response. It should not be described as a wholly separate circuit family from the Diablo.

## Sound

OKKO describes the Dirty Diablo as tweaked for earlier, slightly grittier breakup, more saturation, and a fatter, wider sound. The current Raw/Black product uses the familiar Diablo Dual enclosure architecture.
