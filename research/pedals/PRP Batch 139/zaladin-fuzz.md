# Calangary Pedals - Zaladin Fuzz

- **Builder:** Calangary Pedals
- **Catalog type:** Fuzz
- **Primary research sources:** Effects Database exact-model page; Effects Database December 2016 weekly update; Guitar Pedal X Zonk Machine overview.
- **Identity:** Effects Database identifies the pedal as the Calangary Pedals Zaladin Fuzz and dates the exact model page to December 25, 2016.
- **Colorways:** No verified production colorway list was found. Exact-model imagery is present on the Effects Database listing, but no direct image file met the archive's local caching standard in this pass.
- **Versions:** No numbered production versions were verified.
- **Version changes:** No documented model revision or circuit revision was located.
- **Controls / construction:** The exact-model description explicitly references **Attack** and **Fuzz** adjustments and describes point-to-point wiring, 3PDT true bypass, an internal bias trimpot, and an onboard voltage inverter for standard 9V DC powering.
- **Transistor type:** The builder description specifies hand-matched, measured NOS Mullard OC75 black-glass transistors plus a NOS Russian germanium transistor.
- **Diode type:** Not documented by the checked exact-model sources.
- **Sound description:** The builder describes the Zaladin as a recreation of the early 1965 John Hornby Skewes Zonk Machine, with a complex, aggressive and dynamic voice that remains sensitive to playing touch. The same description says lower Attack settings can give crunchy power-chord punch, while higher Fuzz settings become thicker, gnarlier and buzzier.
- **Power / electrical notes:** The unit uses an onboard voltage inverter and is described as compatible with a 9V DC adapter or chained power supply. Exact current draw was not documented on the exact-model page.
- **Photo status:** No exact-model image promoted to the local archive in this batch.
- **Research confidence:** High for identity, provenance, transistor/build claims and the documented tonal description; medium for the historical Zonk/Mk-I lineage because that relationship is presented in builder copy rather than independently established.
