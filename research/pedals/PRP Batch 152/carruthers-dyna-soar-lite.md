# Carruthers Dyna-Soar Lite

- **Builder:** Carruthers
- **Catalog type:** Fuzz
- **Catalog identity:** Dyna-Soar Lite
- **What this pedal is:** A rarer early-1980s Carruthers fuzz in the Dyna-Soar family, using a different transistor configuration to produce a lower-gain response.
- **Colorways:** A documented surviving example has orange lettering on the enclosure; the exact factory color range is not established.
- **Versions:** Dyna-Soar Lite; original Dyna-Soar is maintained as a separate catalog identity.
- **Version changes:** The Lite keeps the same basic circuit family as the Dyna-Soar but uses a different transistor configuration that reduces the extreme gain and volume of the original.
- **Transistor type:** Exact transistor part numbers are not securely documented in the reviewed public sources.
- **Diode type:** Exact diode type is not securely documented.
- **Controls / switching:** Exact factory control labels are not consistently documented in surviving references.
- **Power:** Exact factory power specification is not securely documented.
- **Sound:** Surviving documentation describes the Lite as gritty, lower-gain, and closer to an overdrive than the much more aggressive original Dyna-Soar. It can work into a slightly dirty amplifier or in front of other drive pedals.
- **Research confidence:** Medium because surviving examples and documentation are scarce.
