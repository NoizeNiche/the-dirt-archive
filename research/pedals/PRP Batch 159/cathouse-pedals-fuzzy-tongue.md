# Cathouse Pedals Fuzzy Tongue

- **Builder:** Cathouse Pedals
- **Catalog type:** Fuzz
- **Catalog identity:** Fuzzy Tongue
- **What this pedal is:** A hand-built, individually balanced version of the classic Fuzz Face concept using matched old germanium transistors.
- **Colorways:** A pink enclosure/finish is documented in contemporary review coverage.
- **Versions:** Fuzzy Tongue.
- **Version changes:** The reviewed documentation describes a production model updated to use a standard 9V DC Boss-style center-negative supply while retaining the germanium Fuzz Face character.
- **Transistor type:** Matched and biased germanium transistors; Effects Database describes a pair from the 1960s-70s era.
- **Diode type:** Not documented.
- **Controls / switching:** Fuzz, Volume.
- **Power:** 9V DC, Boss-style center-negative.
- **Sound:** The pedal covers warm, creamy, sustain-heavy fuzz from lower-rumble settings through larger saturated tones. Individual balancing and germanium matching are emphasized in the documented design.
- **Research confidence:** High for the Fuzz Face relationship, germanium construction, controls, and power arrangement; moderate for undocumented component details.
