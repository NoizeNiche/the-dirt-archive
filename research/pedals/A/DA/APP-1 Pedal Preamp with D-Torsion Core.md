# A/DA — APP-1 Pedal Preamp with D-Torsion Core

## PRP identity
- **Archive parent:** APP-1 Pedal Preamp with D-Torsion Core
- **Builder:** A/DA (Analog/Digital Associates)
- **Catalog type:** Overdrive
- **Identity:** A/DA's two-channel all-analog pedal preamp built around D-TORSION CORE dynamics control.

## What this pedal is
The APP-1 is a **two-channel analog guitar preamp** designed to move from clean response through overdrive and distortion while preserving playing dynamics. A/DA describes its D-TORSION CORE as a player-responsive system that reacts to signal level and can make the transition into breakup depend on how hard the strings are played. [1][2]

Effects Database published the exact-model entry on **October 17, 2011** and reproduces an A/DA March 20, 2012 press release announcing the APP-1. These are documentation dates, not a claimed first manufacturing date. [1]

## Main controls / functions
The APP-1 provides:
- two independent preamp channels,
- D-TORSION **Dynamics** control,
- independent pre-distortion **Voicing** and passive tone-stack functions,
- Master level,
- a footswitchable Boost circuit,
- dual-buffered effects loop with return-level adjustment,
- tuner output,
- true/hardwire bypass. [1][2]

A/DA's press material describes the channel voicings as **Clean, OD and Distortion**, while the user manual documents operating combinations for PREAMP + BOOST, BOOST only, FX LOOP operation, tuner mute and true bypass. [1][2]

## D-TORSION CORE
The manual describes D-TORSION as responding to the signal level of the strings. The **Dynamics** control interacts with the **Drive** setting so harder picking can trigger progressively more overdrive/distortion, while higher Dynamics settings can create a pronounced “bloom” effect. [2]

## Effects loop
The APP-1 uses a **dual-buffered effects loop**. A low-impedance send drives the external effects chain and a high-impedance buffered return with adjustable level compensates for losses in that chain. The manual also describes a loop switch for A/B comparison and level matching. [2]

## Boost
The Boost circuit is post-Master and can add up to approximately **+16 dB** according to the A/DA/Effects Database documentation. [1][2]

## Construction / power
A/DA describes the APP-1 as an all-analog signal path in an all-steel industrial-grade enclosure, hand made in California. The retained manual identifies a 12V external supply. [1][2]

## Versions
The available manual is marked **V.2**, but that establishes a manual revision, not a confirmed separate hardware revision. The archive therefore keeps one APP-1 parent identity unless stronger production evidence appears. [2]

## Sound
A/DA positions APP-1 as a dynamics-focused preamp capable of clean, overdriven and distorted sounds without requiring constant amp-side knob changes. The manual emphasizes touch-responsive breakup, bloom and preserving dynamics, while the passive tone stacks and effects loop make it suitable as a board-level preamp rather than simply a dirt stompbox. [1][2]
