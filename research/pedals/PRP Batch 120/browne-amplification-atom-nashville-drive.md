# Browne Amplification — Atom - Nashville Drive

## PRP identity
- **Builder:** Browne Amplification
- **Catalog type:** Overdrive
- **Identity:** Nashville-inspired overdrive predecessor to the current ALKENE.

## What this pedal is
Browne's surviving product documentation identifies the ATOM as a Nashville-inspired drive. The current ALKENE page preserves ATOM-specific audio examples and dimensions, indicating the older ATOM identity in the same Nashville-drive lineage. [1]

## Colorways

## Versions and factory options
- 4.8 x 2.64 x 1.6 inches, with 2.25 inches including knobs
- 9V power
- 75mA draw
- Soft switching
- Adjustable startup state
- Nashville-drive voicing [1]

Browne Amplification Atom - Nashville Drive
