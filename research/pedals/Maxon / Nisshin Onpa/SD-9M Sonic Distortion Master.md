- **Identity note:** The archive currently files this record under Maxon / Nisshin Onpa. Exact-model references identify the SD-9M as a 2012 Ibanez update/reissue of the Maxon/Ibanez SD-9 Sonic Distortion, with additional gain and midrange controls.

## What this pedal is
The SD-9M is the later modified version of the SD-9 Sonic Distortion. Exact-model technical documentation describes the SD-9M as a 2012 update that adds a switchable high-gain stage and a dedicated midrange control while retaining the core SD-9 distortion concept. [1][2]

## Controls
The documented control architecture includes:
- **Level**
- **Tone**
- **Distortion**
- **Gain/High-Gain switching**
- **Midrange control / midrange switching** [1][2]

The added gain stage provides a substantially higher-gain setting than the standard SD-9 circuit, while the added midrange function gives more control over the pedal's voice. [1][2]

## Sound
The SD-9M retains the aggressive SD-9-style distortion character while offering more gain and additional midrange control. The added high-gain mode extends the pedal into a denser, heavier distortion range, while the midrange control provides more flexibility for shaping how the distortion sits against an amp. [1][2]
