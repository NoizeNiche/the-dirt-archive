# Blackstar Amplification - HT-DIST

## PRP identity
- **Builder:** Blackstar Amplification
- **Catalog type:** Distortion

## Research
The HT-DIST is a high-voltage valve distortion pedal using an ECC83 / 12AX7 tube. Its core control set is Gain, Level, Bass, Middle, Treble and Blackstar's ISF control. ISF shifts the shared tone network between a more American response at minimum and a more British response at maximum.

The pedal includes both a normal output and a speaker-emulated output for recording or mixing-desk use. The gain range is intended to move from crunch into full distortion, with the EQ and ISF providing broad tonal shaping.

## Controls and connectivity
- Gain
- Level
- Bass
- Middle
- Treble
- ISF
- Standard output
- Speaker-emulated output
- ECC83 / 12AX7 valve
- 22V DC / 1.1A supplied adapter
