# BLAMMO! Electronics - TNYDUMBLE

## PRP identity
- **Builder:** BLAMMO! Electronics
- **Catalog type:** Overdrive

## Research
TNYDUMBLE is BLAMMO!'s compact version of the Dumble-style DIY overdrive kit, with circuit-separation modifications built into the production pedal. The JFET clean boost and overdrive are separated so they can be used independently and in either order.

The boost section adds a high-frequency control and an input control that reduces low end and gain together. The overdrive retains an internal presence control and asymmetrical MOSFET clipping. Both sides use relay-based true-bypass soft switching.

## Features
- JFET clean boost
- Overdrive section
- Independent boost and drive switching
- Order switching
- Boost high-frequency control
- Input control for bass/gain shaping
- Internal presence control
- Asymmetrical MOSFET clipping
- 125B enclosure
- 9V center-negative
- 32mA one side / 60mA both sides
