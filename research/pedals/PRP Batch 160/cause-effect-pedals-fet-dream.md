# Cause & Effect Pedals (CE Pedals) FET Dream

- **Builder:** Cause & Effect Pedals (CE Pedals)
- **Catalog type:** Distortion / Overdrive
- **Catalog identity:** FET Dream
- **What this pedal is:** A hand-built overdrive/distortion centered on a tube-like JFET input stage with pre- and post-distortion tone shaping.
- **Colorways:** Original boutique presentation documented.
- **Versions:** FET Dream.
- **Version changes:** No separate production version was confirmed in the reviewed sources.
- **Transistor type:** Individually selected and hand-tuned JFET transistors in the input stage.
- **Diode type:** Not documented in the reviewed sources.
- **Controls / switching:** Girth, Drive, Lean, Level; true bypass.
- **Power:** 9V DC, center-negative; 9V battery operation is also documented.
- **Sound:** Girth shapes bass and lower-mid content before distortion; Drive spans from clean boost to substantial clipping; Lean shapes the post-distortion treble response with variable emphasis; Level controls final output.
- **Research confidence:** High for the control set, JFET input stage, power arrangement, and signal-flow description.
