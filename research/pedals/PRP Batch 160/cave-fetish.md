# Cave Pedals FETish

- **Builder:** Cave Pedals
- **Catalog type:** Fuzz / Overdrive
- **Catalog identity:** FETish
- **What this pedal is:** Cave Pedals' flagship all-JFET preamp, overdrive and fuzz platform.
- **Colorways:** Multiple current formats/enclosure variants are offered; these are treated as format/cosmetic differences rather than separate circuit identities here.
- **Versions:** FETish; current family includes multiple formats, with a FETish Prime form documented separately by third-party catalog coverage.
- **Version changes:** The current Cave site describes FETish as available in multiple formats. A single version chronology is not asserted without a version-specific source.
- **Transistor type:** JFET.
- **Diode type:** Not documented.
- **Controls / switching:** The FETish Prime format is documented with Pre, Dirt, Flavour and Post controls and a two-footswitch layout for Drive/Fuzz mode and bypass. Exact control layouts can vary by format.
- **Power:** FETish Prime is documented as 9V DC center-negative.
- **Factory modifications:** None documented.
- **Sound:** FETish is designed as a preamp, overdrive and fuzz platform, using all-JFET gain stages to move from lower-gain drive through more saturated fuzz textures.
- **Research confidence:** High for the all-JFET family identity; moderate for version-specific controls and power.
