# CMC Audio — PROTO TYPE V2

## PRP identity
- **Archive parent:** PROTO TYPE V2
- **Builder:** CMC Audio
- **Catalog type:** Overdrive
- **Identity:** CMC Audio PROTO TYPE V2, a bass-oriented low/medium-gain overdrive with parallel clean and drive paths.

## What this pedal is
CMC Audio describes PROTO TYPE V2 as a low-to-medium gain overdrive designed to retain bass low end. The signal is split into clean and overdriven paths, then recombined. V2 refines the original design while retaining the core parallel-path architecture. [1]
