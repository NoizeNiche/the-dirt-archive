# Benson Amps - Portable Distortion 424 MKII

## PRP identity
- **Archive parent:** Portable Distortion 424 MKII
- **Builder:** Benson Amps
- **Catalog type:** Distortion
- **Identity:** Enhanced pedal recreation of a classic cassette 4-track 424 MkII input channel.

## What this pedal is
The Portable Distortion 424 MKII recreates the raw, grimy distortion texture and broad EQ of a classic cassette 4-track recorder preamp. Benson adds a bypassable buffer so the pedal can behave differently with high-impedance guitar signals and can be used for clean boost, treble boost, warm/dark textures, or chaotic grind.

## Versions and factory options
### Portable Distortion 424 MKII
- Treble
- Fader
- Bass
- Trim
- LO Z mode
- Bypassable input buffer
- 9V DC operation

## Version changes
The **MKII** is the expanded version represented in the current Benson product line. The distinguishing feature documented by Benson is the added bypassable buffer relative to the more direct recreation concept.

## Sound
With the buffer engaged the pedal can work across a broader range of input sources, while bypassing it emphasizes the direct-to-original-recorder character. The broad EQ and distortion range can cover cleaner boosts, cutting treble emphasis, warm dark sounds, and deliberately chaotic preamp grind.
