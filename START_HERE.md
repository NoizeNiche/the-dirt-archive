- Understand the current repository state.
- Identify the source of truth.
- Make the smallest coherent change.

After every change:
1. Validate the repository contents.
2. Verify the actual live/rendered result where the tooling allows.
3. Re-check that the result matches the requested change.
4. Update `CURRENT_STATE.md`.
5. Update `research/BREADCRUMB.md`.
6. Commit a recoverable state.

Never treat a successful GitHub file edit or commit as proof that the live site is correct.
